What the bot reads in a thread run:

- `review-sheet.md`: the one page of rules for the writer and the reviewer (pass mark, voice, hooks, structure, compliance). Change rules here.
- `common-mistakes.md`: what the writer checks before the first review. Update it from the weekly report's top fail reasons.
- `topic-bank.md`: the topics and the recycling rule.

History, not read in runs: `scoring-parameters.md`, `dna-digest.md`.

The pain-point bank lives in the `Pain Points` tab of the DuitJeBro CRM sheet, so the bot can mark rows used.
